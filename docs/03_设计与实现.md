## 0. 一页结论（先看这个）

| 问题 | 答案 |
|---|---|
| 1.15.1 与 8.19.16 的 HIFI 参数一样吗？ | **核心完全一样**。`mixer_paths_tasha.PD1610.xml` 118,532 B vs 119,329 B，差异 195 行**全是** MultiMedia8/9、EC Reference、HDMI 等通路扩展。HIFI 相关控件（`HiFi Mode Switch`/`HPHL-HPHR Volume`/`SmartPA Switch`/`DSD`）逐字节一致 |
| LOS16 缺什么？ | **不缺 mixer**（9 个文件齐全，`mixer_paths_tasha.PD1610.xml` = 119,329 B，与 8.19.16 完全相同）。缺的是**触发 HIFI 设备的 App** |
| HIFI 怎么触发？ | HAL 暴露 `setParameters` key：`hifi-playback` / `hifi-record` / `hifi_i2s_clock_rate` / `dsdvol_index` / `DSDEnable`。**不需要改 mixer、不需要刷机** |
| 能实时调吗？ | **能**。走 `AudioManager.setParameters()`（反射调用），无需重启 |
| APP 怎么做？ | 参照 tmproot：**纯 Java + 代码构建 UI（不用 XML 布局）**，深色 Material 3 风格，用 Magisk `su` 做需要 root 的操作 |

**HIFI 核心控件（两版完全一致）**：

| 控件名 | 取值 | 含义 |
|---|---|---|
| `HiFi Mode Switch` | `Off` / `HiFi` / `DSD` | HIFI 模式开关，**核心** |
| `DSD SampleRate Switch` | `Off` / `On` | DSD 采样率 |
| `HiFi DSD Volume Switch` | `19`（0..31，5 bit） | DSD 音量，官方默认 19 |
| `SmartPA Switch` | `0` / `1` | 智能功放（外放用） |
| `HPHL Volume` | `14` / `20` | 左耳音量（0..20 或更大，见下） |
| `HPHR Volume` | `14` / `20` | 右耳音量 |

**`headphone-hifi` path 完整内容（只有 5 个控件，这是最小可复现集）**：
```xml
<path name="headphone-hifi">
    <ctl name="TERT_MI2S Bit Format" value="S24_LE" />
    <ctl name="TERT_MI2S_RX Channels" value="Two" />
    <ctl name="HiFi Mode Switch" value="HiFi" />
    <ctl name="Headphone Rx Mixer I2S_RX" value="1" />
    <ctl name="TERT_MI2S mode" value="Slave" />
</path>
```
**`headphone-hifi-DSD` path**：与上面相同，但 `HiFi Mode Switch=DSD`、`DSD SampleRate Switch=On`。

### 2.3 三个页面

**页 1 · 状态（只读，无需 root）**
- 当前 HIFI 模式（从 DT + `dumpsys` 推断）
- 耳机增益 4 档：`{4,3,1,1}`
- 阻抗阈值：`{4,24,38,70} Ω`
- ES9038 DAC 参数表（16 个 u32）
- 当前插入设备（耳机/外放）

**页 2 · 调节（核心）**
- **HIFI 模式**：`Off` / `HiFi` / `DSD` → 调 `setParameters("hifi-playback=...")`
- **耳机音量 L/R**：滑块 0..20（对应 `HPHL/HPHR Volume`）
- **DSD 音量**：滑块 0..31（对应 `dsdvol_index` / `HiFi DSD Volume Switch`，默认 19）
- **I2S 时钟**：`hifi_i2s_clock_rate` 可选值（需实测）
- 每个控件旁显示"当前值"和"官方默认值"

**页 3 · 关于**
- 两版参数对比表（1.15.1 vs 8.19.16）
- 来源说明、风险提示、回滚方法

### 2.4 关键技术决策

| 需求 | 方案 | 理由 |
|---|---|---|
| 实时切 HIFI | `AudioManager.setParameters()` 反射 | HAL 已支持，无需重启 |
| 读 DT 参数 | `FileInputStream` 读 `/sys/firmware/devicetree/base/...` | 无需 root，全局可读 |
| 写 mixer 持久化 | Magisk 模块 + `su` 写文件 | 重启后仍生效 |
| 需要 root 时 | `Runtime.exec("su -c ...")` | LOS16 已有 Magisk |
| UI | 纯 Java 代码构建 | 学 tmproot，避免 XML 资源 |

### 2.5 风险与边界

- **`setParameters` 是 @hide API**，需反射调用；某些 ROM 会限制，需实测
- **改 mixer XML 会影响所有音频路径**（外放/通话/蓝牙），改前必须备份
- **不碰内核、不碰 boot**，全部在用户态
- 回滚：删 Magisk 模块 + 重启；或 APP 里"恢复官方默认"按钮

### 3.2 HifiController.java（核心）

```java
package com.pd1610.hifictl;

import android.content.Context;
import android.media.AudioManager;
import android.util.Log;
import java.lang.reflect.Method;

/**
 * HIFI 控制核心。两条通路：
 *  1) setParameters —— 实时，走 HAL，无需 root
 *  2) writeMixerValue —— 持久化，需 root，写 /vendor/etc/mixer_paths_tasha.PD1610.xml
 */
public final class HifiController {
    private static final String TAG = "HifiCtl";
    private final AudioManager am;

    public HifiController(Context ctx) {
        am = (AudioManager) ctx.getSystemService(Context.AUDIO_SERVICE);
    }

    /** 反射调用 AudioManager.setParameters(String) —— @hide API */
    private boolean setParameters(String kv) {
        try {
            Method m = AudioManager.class.getMethod("setParameters", String.class);
            m.setAccessible(true);
            m.invoke(am, kv);
            Log.i(TAG, "setParameters OK: " + kv);
            return true;
        } catch (Throwable t) {
            Log.e(TAG, "setParameters FAIL: " + kv, t);
            return false;
        }
    }

    /** 切换 HIFI 模式：off / hifi / dsd */
    public boolean setHifiMode(String mode) {
        switch (mode) {
            case "off":
                return setParameters("hifi-playback=false") &
                       setParameters("DSDEnable=0");
            case "hifi":
                return setParameters("DSDEnable=0") &
                       setParameters("hifi-playback=true");
            case "dsd":
                return setParameters("hifi-playback=true") &
                       setParameters("DSDEnable=1");
            default:
                return false;
        }
    }

    /** DSD 音量：0..31，官方默认 19 */
    public boolean setDsdVolume(int v) {
        if (v < 0) v = 0;
        if (v > 31) v = 31;
        return setParameters("dsdvol_index=" + v);
    }

    /** I2S 时钟：具体可选值需实测，先支持常见档 */
    public boolean setI2sClockRate(int hz) {
        return setParameters("hifi_i2s_clock_rate=" + hz);
    }

    /** 读 DT 里 4 档耳机增益，返回 {4,3,1,1} 这样的数组 */
    public int[] readHphGain() {
        byte[] raw = DtReader.readBeU32("/sys/firmware/devicetree/base/soc/sound-9335/vivo,wcd-hph-gain");
        if (raw == null) return null;
        int n = raw.length / 4;
        int[] out = new int[n];
        for (int i = 0; i < n; i++) out[i] = ((raw[i*4]&0xff)<<24)|((raw[i*4+1]&0xff)<<16)
                                          |((raw[i*4+2]&0xff)<<8)|(raw[i*4+3]&0xff);
        return out;
    }

    /** 读 DT 阻抗阈值，返回 {4,24,38,70} */
    public int[] readImpedDefs() {
        byte[] raw = DtReader.readBeU32("/sys/firmware/devicetree/base/soc/sound-9335/vivo,wcd-imped-defs");
        if (raw == null) return null;
        int n = raw.length / 4;
        int[] out = new int[n];
        for (int i = 0; i < n; i++) out[i] = ((raw[i*4]&0xff)<<24)|((raw[i*4+1]&0xff)<<16)
                                          |((raw[i*4+2]&0xff)<<8)|(raw[i*4+3]&0xff);
        return out;
    }

    /** 读 ES9038 DAC 参数表，16 个 u32 */
    public int[] readDacParams() {
        byte[] raw = DtReader.readBeU32("/sys/firmware/devicetree/base/soc/i2c@75b6000/dac@48/vivo,params");
        if (raw == null) return null;
        int n = raw.length / 4;
        int[] out = new int[n];
        for (int i = 0; i < n; i++) out[i] = ((raw[i*4]&0xff)<<24)|((raw[i*4+1]&0xff)<<16)
                                          |((raw[i*4+2]&0xff)<<8)|(raw[i*4+3]&0xff);
        return out;
    }
}
```

### 3.3 DtReader.java

```java
package com.pd1610.hifictl;

import android.util.Log;
import java.io.File;
import java.io.FileInputStream;
import java.io.ByteArrayOutputStream;

/** 读 device tree 二进制属性（大端 u32 数组） */
public final class DtReader {
    private static final String TAG = "DtReader";

    public static byte[] readBeU32(String path) {
        File f = new File(path);
        if (!f.exists() || !f.canRead()) {
            Log.w(TAG, "not readable: " + path);
            return null;
        }
        try (FileInputStream in = new FileInputStream(f)) {
            ByteArrayOutputStream bo = new ByteArrayOutputStream();
            byte[] buf = new byte[4096];
            int n;
            while ((n = in.read(buf)) > 0) bo.write(buf, 0, n);
            return bo.toByteArray();
        } catch (Throwable t) {
            Log.e(TAG, "read fail: " + path, t);
            return null;
        }
    }

    /** 按大端 u32 解析，返回可读字符串 */
    public static String describe(String path) {
        byte[] b = readBeU32(path);
        if (b == null) return "(不可读)";
        if (b.length == 0) return "(空属性)";
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i + 3 < b.length; i += 4) {
            int v = ((b[i]&0xff)<<24)|((b[i+1]&0xff)<<16)|((b[i+2]&0xff)<<8)|(b[i+3]&0xff);
            if (sb.length() > 0) sb.append(", ");
            sb.append(v);
        }
        return sb.toString();
    }
}
```

### 3.4 RootShell.java

```java
package com.pd1610.hifictl;

import java.io.BufferedReader;
import java.io.InputStreamReader;

/** 简单的 su 命令执行封装 */
public final class RootShell {
    public static class Result {
        public final int code;
        public final String out;
        public final String err;
        Result(int c, String o, String e) { code = c; out = o; err = e; }
    }

    public static Result run(String cmd) {
        try {
            Process p = Runtime.getRuntime().exec(new String[]{"su", "-c", cmd});
            StringBuilder out = new StringBuilder(), err = new StringBuilder();
            try (BufferedReader r = new BufferedReader(new InputStreamReader(p.getInputStream()))) {
                String l; while ((l = r.readLine()) != null) out.append(l).append('\n');
            }
            try (BufferedReader r = new BufferedReader(new InputStreamReader(p.getErrorStream()))) {
                String l; while ((l = r.readLine()) != null) err.append(l).append('\n');
            }
            int c = p.waitFor();
            return new Result(c, out.toString(), err.toString());
        } catch (Throwable t) {
            return new Result(-1, "", t.toString());
        }
    }

    public static boolean hasRoot() {
        return run("id").out.contains("uid=0");
    }
}
```

```java
package com.pd1610.hifictl;

import android.app.Activity;
import android.os.Bundle;
import android.view.View;
import android.widget.*;

public final class MainActivity extends Activity {
    private static final int PAGE_STATUS = 0, PAGE_TUNE = 1, PAGE_ABOUT = 2;
    private final FrameLayout[] pages = new FrameLayout[3];
    private int page = PAGE_STATUS;
    private Ui ui;
    private HifiController ctl;

    @Override protected void onCreate(Bundle b) {
        super.onCreate(b);
        ui = new Ui(this);
        ctl = new HifiController(this);

        LinearLayout root = ui.column();
        root.setBackgroundColor(Ui.BG);

        // 顶部导航
        LinearLayout nav = new LinearLayout(this);
        nav.setOrientation(LinearLayout.HORIZONTAL);
        String[] names = {"状态", "调节", "关于"};
        for (int i = 0; i < names.length; i++) {
            final int idx = i;
            TextView tab = ui.heading(names[i], 14, idx == 0 ? Ui.PRIMARY : Ui.MUTED);
            tab.setPadding(ui.dp(16), ui.dp(12), ui.dp(16), ui.dp(12));
            tab.setOnClickListener(v -> showPage(idx));
            nav.addView(tab);
        }
        root.addView(nav, new LinearLayout.LayoutParams(-1, -2));

        // 页面容器
        FrameLayout container = new FrameLayout(this);
        for (int i = 0; i < 3; i++) {
            pages[i] = new FrameLayout(this);
            pages[i].setVisibility(i == PAGE_STATUS ? View.VISIBLE : View.GONE);
            container.addView(pages[i], new FrameLayout.LayoutParams(-1, -1));
        }
        pages[PAGE_STATUS].addView(buildStatus(), new FrameLayout.LayoutParams(-1, -1));
        pages[PAGE_TUNE].addView(buildTune(), new FrameLayout.LayoutParams(-1, -1));
        pages[PAGE_ABOUT].addView(buildAbout(), new FrameLayout.LayoutParams(-1, -1));

        root.addView(container, new LinearLayout.LayoutParams(-1, 0, 1f));
        setContentView(root);
    }

    private void showPage(int idx) {
        for (int i = 0; i < 3; i++) pages[i].setVisibility(i == idx ? View.VISIBLE : View.GONE);
        page = idx;
    }
```

### 4.1 阶段 A：先验证 setParameters（**最重要，先做这个**）

## 5. 关键坑（本任务特有）

| # | 坑 | 处理 |
|---|---|---|
| 1 | 1.15.1 的 system.img 是 **sparse**，debugfs 读不了 | 先用 `sparse2raw.py` 转 raw（已写好） |
| 2 | 1.15.1 的 mixer 在 **`/etc/`**，8.19.16 在 **`/vendor/etc/`** | 写清单/脚本时路径要分开 |
| 3 | `AudioManager.setParameters` 是 **@hide** API | 必须反射，且要 `setAccessible(true)` |
| 4 | `strings` 输出的 `hifi-playback` 可能是 **backend 名**而非 setParameters key | 必须用 logcat 验证真实 key（阶段 A） |
| 5 | 改 mixer 会影响**所有**音频路径 | 改前备份，提供一键恢复 |
| 6 | LOS16 的 `/vendor` 是 `/system/vendor` 软链 | Magisk 模块路径写 `system/vendor/etc/` |
| 7 | Magisk 模块 `versionCode` 超 int32 会不挂载 | 用 ≤ 2147483647 |
| 8 | `adb push` 写 `/data/adb/` 会 Permission denied | 先推 `/data/local/tmp` 再 `su -c cp` |
| 9 | WSL `bash -lc` 吞变量 | 写独立 `.sh` 文件执行 |
| 10 | 两版 `mixer_paths_tasha.PD1610LG4.xml` 是**不同机型变体** | PD1610 用不带 LG4 的；LG4 可能是另一批次 |
