# HifiCtl v2.0 · 整体重构规格（Wupp 风格 / WhatsApp 深色系）

> 目标机：vivo Xplay6 (PD1610) / LineageOS 16 / **Android 9 (API 28)** / 720×1280 / density=2.0
> 参考对象：`wupp.apk`（`com.wupp.app` v0.3.2，全 Compose 构建，资源混淆，静态无法取色）
> 取色依据：其 lottie 资源实证主色 `#25D366`（WhatsApp 绿）+ 辅助蓝紫，交互骨架为 IM 型
> 用户裁决：按 WhatsApp 系推导 / 深色为主 / 震度 0–100% 连续可调 + 试震

## 0. 红线（违反即失败）

1. `HifiController.java` / `DtReader.java` / `RootShell.java` **一个字节都不许改**。参数调节的所有接口语义保持不变。
2. 不引入 support/androidx、不加 layout XML、不加第三方依赖。纯 framework + 纯代码构建 UI。
3. API 28 可用。禁用 `RenderEffect` / `RuntimeShader` / 大半径 `BlurMaskFilter`。
4. 单文件 ≤ 500 行。全中文文案，无 emoji。
5. `versionCode=4`、`versionName=2.0`。包名 `com.pd1610.hifictl` 不变。
6. 必须能用 `app_src/debug.keystore` 签名（SHA-1 `6355E595FF718236B564A8A9EC8303C000065AC5`）以覆盖安装已装版本。

## 3. 组件规格

### 3.1 BottomNav（底部导航）
- 高 64dp，背景 `BG_BAR`，顶部 1dp `HAIRLINE`。
- 每项：图标 24dp（Canvas 绘制，见 3.9）+ 文字 11sp，间距 4dp，整项热区 48dp。
- 选中：图标与文字 `GREEN_DEEP`，图标底 **64×32dp 圆角 16 的 `GREEN_WASH` 药丸**；未选中 `TEXT_3`。
- 切换：药丸与颜色 180ms 过渡；页面淡入 160ms（`alpha 0→1` + `translationY 6dp→0`），**不重建页面**。
- 点击有触感（走 5.1 的震度）。

### 3.2 SectionHeader（分区标题）
- 13sp medium `GREEN_DEEP`，左右 16dp，上间距 20dp / 下间距 8dp。
- 纯文字，无背景。

### 3.3 ListRow（列表行，WhatsApp 核心形态）
- 高 72dp（有副标）/ 56dp（无）。
- 左：40dp 圆（`GREEN_WASH` 底 + 20dp 图标，图标色跟随语义）；无图标时用 8dp 色点。
- 中：标题 16sp `TEXT`；副标 14sp `TEXT_2`，单行省略。
- 右：chevron（16dp，`TEXT_3`）或数值（14sp `TEXT_2`）或开关。
- 整行 ripple（`#1FFFFFFF`），无圆角遮罩（通栏）。
- 展开详情的行：chevron 旋转 90°，详情 13sp `TEXT_2` 缩进 56dp 显示。

### 3.4 SegmentedControl（分段，绿滑块版）
- 槽高 44dp，`SURFACE_2` 底，圆角 12，内缩 4dp。
- 滑块：`GREEN_DEEP` 实底（不是半透明描边），圆角 9，高 36dp。
- 选中文字 `ON_GREEN` medium 15sp；未选中 `TEXT_2` regular 15sp。
- 滑动 200ms `DecelerateInterpolator`；点击 haptic；支持「无选中」（`clearSelection()`，滑块 alpha 0）。

### 3.5 InlineBanner（卡内结果条）
- 圆角 12，内边距 12×10，左侧 3×16dp 语义竖条，右侧可带文字按钮 + 「×」。
- 语义底：info `#12323B` / ok `#0F2B24` / warn `#2E2415` / danger `#2E1719`，描边用对应色 30% alpha。
- 文案「结论 + 下一步」，例：`已切到 HiFi · 重开播放后生效` + 动作 `我已重开播放`。
- **不自动消失**（唯一例外：重新对账成功后 3s 收起）。

### 3.6 Slider（震度 / DSD 音量共用皮肤）
- 轨道 4dp：已走 `GREEN_DEEP`，未走 `#3B4A54`，圆角 2。
- Thumb 直径 16dp，`GREEN_DEEP` 实心 + 2dp `BG_PAGE` 描边；按下放大到 20dp。
- 数值在右侧 32sp medium（DSD）或 14sp（震度行内）。

### 3.7 ConfirmSheet（底部确认层）
- 顶部圆角 28，背景 `SURFACE_2`，遮罩 `#99000000`，从下 +100% 滑入 220ms。
- 标题 20sp，说明 14sp `TEXT_2`；按钮行：次按钮（描边 `HAIRLINE`，`TEXT`）/ 危险按钮（`DANGER` 实底，`#2A0F12` 文字）。
- **必须做防双击**：确认回调首行判 `dismissed`，并立刻 `confirm.setEnabled(false)`、`cancel.setEnabled(false)`、`overlay.setClickable(false)`。退场动画期间 overlay 仍在窗口上且命中矩形不变。
- panel 必须 `setClickable(true)`，否则点空白区穿透到遮罩误关闭。

### 3.8 BusyButton
- 高 48dp，圆角 12，`SURFACE` 底 + `HAIRLINE` 描边，文字 14sp medium。
- busy：文字改「备份中…」+ 16dp 转圈（tint `GREEN_DEEP`）+ `setEnabled(false)` + alpha 0.6。
- 完成后把结果写入卡片底部 caption（带 `HH:mm:ss`）。

### 3.9 图标（无资源文件，全部 Canvas 绘制）
在 `Icons.java` 里用 `Path` 画 24dp 线性图标（stroke 2dp，`Paint.Cap.ROUND`，`Style.STROKE`）：
- `sliders`（控制）：三条横线 + 两个滑块钮
- `pulse`（状态）：心电图折线
- `gear`（设置）：齿轮或三条长短线
- `info`（关于）：圆圈 + i
- `refresh`（刷新）：圆弧 + 箭头
- `chevron`：›
- `check` / `dot`：备用
每个图标提供 `Drawable draw(int color)` 或 `void draw(Canvas, Rect, int color)`，用 `setColorFilter` 着色。

## 4. 交互逻辑（沿用并强化 v1.2 已验收的机制）

### 4.1 模式切换：乐观更新 + 回读对账
```
点击段 i
 → 立即：滑块 200ms + 文字选中 + 触感
 → 立即：hero 标题切目标模式，副标「已发送，等待重开播放」
 → 写 HAL（串行队列，见 4.6）
 → 回读 currentHifiState() 对账：
     匹配   → 副标「正在生效 · enable_hifi = x」+ ok banner（带「我已重开播放」）
     不匹配 → 副标「HAL 未回报」+ warn banner（带「我已重开播放」）
     调用失败 → danger banner「设置失败 · 查看 logcat 过滤 HifiCtl」并回滚滑块到真实状态
```
- **token 竞态**：`applyMode` 在 UI 线程 `++token`，工作线程把 `myToken` 带回比对，过期结果直接丢弃。`rollback()` 也必须走同一套 token 比对，**禁止**在回调里 `token++` 越权作废更晚的点击。
- **DSD 不得谎报**：DSD 无法验证，副标固定「由音源触发，需原生 DSD 播放器」+ info banner，且**不挂**动作按钮（`matches("dsd", *)` 恒 false，挂按钮会误报 warn）。
- **冷启动**：`currentHifiState()` 为空/未知时，分段控件必须 `clearSelection()`，**不许默认高亮 Off**（v1.2 的 F2：会出现"未知 + 未回报 + Off 选中"三个矛盾信号）。

### 4.2 状态页刷新
- 首次进入：后台加载全部快照 + skeleton 占位。
- **再次进入：只静默刷新「HAL 回报」这一行**（单个 `getParameters` 读，不 `removeAllViews`，不动滚动位置与折叠展开态）。
- AppBar 右侧刷新按钮 → 全量重测（骨架屏只在首帧出现；重测时保留旧内容，仅把 HAL 行置为「重测中…」）。

### 4.3 震度（新增，核心需求）
- 存储：`SharedPreferences("ui")` 键 `haptic_pct`，int 0..100，默认 **70**。
- 映射振幅：`pct == 0` → 完全不震；否则 `amp = clamp(round(pct * 255 / 100), 20, 255)`（下限 20 保证可感知）。
- 单次点击：`VibrationEffect.createOneShot(16ms, amp)`（API 26+，API 28 可用）。
- `试震`：连续两下 24ms + 80ms 间隔，便于感受强度。
- 滑块：0..100，`stepSize=10` 吸附（API 26+ 原生支持 `setStepSize`）；拖动实时更新右侧百分比；松手写 SharedPreferences 并震一下当前强度作为反馈。
- 0% 时滑块下方 caption 变 `触感已关闭`（`WARN` 色），否则 `当前震度 70% · 仅影响本 APP 的触感反馈`。
- 实现放 `Haptics.java`：`static void init(Context)`、`static void tap(View)`、`static void buzz(Context)`、`static void setPercent(Context,int)`、`static int percent(Context)`。所有原来的 `performHapticFeedback(KEYBOARD_TAP)` 调用点**全部替换**为 `Haptics.tap(v)`。
- `AndroidManifest.xml` 增加 `<uses-permission android:name="android.permission.VIBRATE" />`。
- 兜底：`Vibrator` 为 null 或无 `VIBRATE` 权限时静默降级为 `performHapticFeedback`，不许崩。

### 4.4 导航与返回键
- 底部 Tab 切换：不重建页面，保留各页滚动位置；记住上次 Tab（`last_page`）。
- 返回键：有 Sheet 先关 Sheet → 非「控制」Tab 回「控制」→ 「控制」Tab 再按退出。
- AppBar 不做返回箭头（Tab 结构不需要）。

### 4.5 危险操作
- 「从备份恢复 mixer」与「恢复官方默认值」都必须过 `ConfirmSheet`；「备份 mixer」不需要确认（非破坏性）。
- 三个根操作进入 busy 态、禁用、完成后 caption 带时间戳。
- `doRestore()` / `doReset()` 首行必须 `if (btn.isBusy()) return;`（配合 3.7 的防双击，双保险）。

### 4.6 HAL 写串行化
- `Ui`（或 `Haptics` 同级的新工具类）里放 `static final ExecutorService IO = Executors.newSingleThreadExecutor();`
- 所有 **写** 操作（模式切换、DSD 音量、I2S 时钟、备份/恢复/恢复默认）走该队列串行执行，保证「最后一次点击」就是 HAL 的最终状态。
- 只读探测（状态页加载、HAL 刷新、对账）**不要**进这条队列，避免被慢 su 卡住。

## 5. 视觉验收要点（自检时逐条对照）

1. 卡片是**平面分层**：`#111B21` 卡片浮在 `#0B141A` 页底上，只有 1dp `#2A3942` 描边或通栏分割线，**没有**半透明玻璃、没有渐变高光、没有投影。
2. 绿色只出现在：选中 Tab、分区标题、分段滑块、滑块已走轨道、主按钮、语义图标。
   - 上限按**实测**定：控制页默认首屏共 7 处（选中 Tab 1 + 三个分区标题 3 + 分段滑块 1 + 滑轨含 thumb 1 + AppBar 状态点 1），这是本设计的正常密度；**超过 7 处**才算过量。
   - 原「≤5」与 §1.1 允许的 6 类用途自相矛盾，已作废。
3. 列表行高 72/56，左圆 40dp，标题 16sp、副标 14sp，chevron 16dp 靠右 16dp。
4. 底部导航 4 项，选中项有 64×32 药丸底 + `#00A884` 图标与文字。
5. 所有可点元素有 ripple 与触感（震度 0 时不震但仍有 ripple）。
6. 页面切换 160ms 淡入上移，Tab 药丸 180ms 过渡，分段滑块 200ms，折叠 200ms，Sheet 220ms。
7. 数值用 32sp medium，不用 mono；mono 只出现在设备树键名/路径/原始数组。
